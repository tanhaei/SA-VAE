# Security and data reporting

Do not open a public issue containing patient data, credentials, internal
BioArc paths, or MIMIC access material.

If sensitive data are accidentally committed:

1. stop distribution immediately;
2. notify the responsible institutional security/privacy contact;
3. revoke exposed credentials;
4. remove the data from Git history using an approved incident process;
5. document the response without republishing the sensitive content.

This research code is not a clinical decision-support device and must not be
used for patient care without independent validation, governance, and safety
review.
